# Senin için bir bahçe

Kasımpatılı, tek sayfalık bir sürpriz sitesi. Next.js, TypeScript, Tailwind CSS ve Framer Motion kullanır.

## Kurulum

```bash
npm install
```

## Çalıştırma

```bash
npm run dev
```

Tarayıcıda [http://localhost:3000](http://localhost:3000) adresini aç.

Üretim derlemesi:

```bash
npm run build
npm start
```

## Vercel

1. Projeyi bir Git sağlayıcısına gönder (GitHub, GitLab veya Bitbucket).
2. [vercel.com](https://vercel.com) üzerinden **Add New Project** de.
3. Bu depoyu seç. Framework olarak Next.js kendiliğinden tanınır.
4. **Deploy** ile yayına al. Ek bir ortam değişkeni gerekmez.

İstersen bilgisayarında Vercel CLI ile de gönderebilirsin:

```bash
npx vercel
```
